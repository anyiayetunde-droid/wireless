Windows

Windows 10/11 · Wireless desktop app

  1. Run the installer — Wireless starts with its own window and tray icon.
  2. A QR code and PIN appear — scan with your phone and start typing.
  3. Close the window to keep it running in the tray; quit from the tray icon.
Download the app Portable — no install

No Node.js needed. Keys go to the focused window — keep Wireless at the same elevation as the apps you type into.

macOS

macOS 12+ · Wireless desktop app (.app)

  1. Download Wireless.app for your chip (Apple Silicon or Intel).
  2. Unzip and drag it to Applications, then open it.
  3. Scan the QR with your phone (or open the URL) and start typing.
Apple Silicon (M-series) Intel

Grant your terminal Accessibility permission the first time (System Settings → Privacy & Security → Accessibility). Mouse needs brew install cliclick.

Android app

Bluetooth keyboard + WiFi Remote

  1. Download and install the APK (allow unknown sources).
  2. Bluetooth mode: pair the phone as a keyboard with your computer.
  3. WiFi Remote mode: connect to the host and let your laptop type into the phone.
Download APK Android source

No prebuilt APK on this host yet — grab the source and build it in Android Studio (steps inside the zip, or see BUILD.md).

iPhone & iPad

No download needed — it's a website that installs like an app

  1. On the phone, open the keyboard page (same Wi-Fi as the host).
  2. Tap Share → Add to Home Screen.
  3. Open it from your home screen — it runs full-screen like a native app.
Open the web app

Works on Android too — every browser can install the PWA.

Already running the host?

The downloads above are this very server, packaged per OS — install it once and it runs on its own. While a host is running, you can also use the host page (QR + PIN) and the laptop page (type into your phone) straight from the browser, no download needed. Android's WiFi Remote mode connects to any running host.
